> 가상 머신 (Virtual Machine)은 컴퓨터 환경을 가상화하여 소프트웨어로 구현한 것입니다. 가상 머신은 하이퍼바이저라는 소프트웨어를 통해 다른 운영체제나 전체 컴퓨팅 환경을 윈도우 안에서 실행할 수 있습니다. 가상 머신은 격리, 보안, 이식성, 효율성 등의 장점을 제공합니다. 가상 머신은 클라우드 애플리케이션 개발 및 배포, 새로운 운영체제 시험, 소프트웨어 테스트, 레거시 애플리케이션 지원 등 다양한 목적으로 사용됩니다.
> Docker 컨테이너 (Docker Container)는 코드와 모든 의존성을 패키징하여 애플리케이션이 다른 컴퓨팅 환경에서도 빠르고 안정적으로 실행될 수 있도록 하는 소프트웨어 단위입니다. Docker 컨테이너 이미지는 코드, 런타임, 시스템 도구, 시스템 라이브러리, 설정 등 애플리케이션을 실행하는 데 필요한 모든 것을 포함하는 경량, 독립적, 실행 가능한 소프트웨어 패키지입니다. Docker 컨테이너는 Open Container Initiative (OCI) 표준과 호환되는 Docker Engine에서 실행됩니다. Docker 컨테이너는 표준화, 경량화, 보안, 통합 등의 장점을 제공합니다. Docker 컨테이너는 다른 플랫폼과 환경에서 애플리케이션을 개발, 배포, 실행하는 데 널리 사용됩니다.
> Apptainer 컨테이너 (Apptainer Container)는 안전하고, 이식성이 높고, 사용하기 쉬운 컨테이너 시스템으로, 절대적인 신뢰성과 재현성을 제공합니다. Apptainer 컨테이너는 이전의 Singularity 프로젝트를 기반으로 하며, 고성능 컴퓨팅 (HPC) 클러스터에서 복잡한 애플리케이션을 간단하고, 이식성 있고, 재현 가능한 방식으로 실행하기 위해 설계되었습니다. Apptainer 컨테이너 이미지는 암호화 서명과 암호화를 지원하는 단일 파일 형식입니다. Apptainer 컨테이너는 100% OCI 호환되는 Apptainer Engine에서 실행됩니다. Apptainer 컨테이너는 검증 가능한 재현성, 격리보다 통합, 암호화, 컴퓨팅 이동성, 루트 없는 실행 등의 특징을 제공합니다. Apptainer 컨테이너는 산업과 학계에서 다양한 분야의 작업에 널리 사용됩니다.
> 파이썬 가상환경 (Python Virtual Environment)은 시스템에 설치된 파이썬과 별도로 파이썬 프로젝트를 작업할 수 있는 격리된 공간입니다. 파이썬 가상환경은 venv 모듈이나 다른 도구들 (예: virtualenv, conda)을 사용하여 생성할 수 있습니다. 파이썬 가상환경은 폴더 구조, 격리된 파이썬 설치, pyvenv.cfg 파일로 구성됩니다. 파이썬 가상환경은 시스템 오염을 피하고, 의존성 충돌을 회피하고, 재현성 문제를 최소화하고, 설치 권한 잠금을 피하는 등의 장점을 제공합니다. 파이썬 가상환경은 파이썬 애플리케이션과 라이브러리를 개발, 테스트, 배포하는 데 널리 사용됩니다.
> 가상 머신은 다양한 게스트 운영체제를 실행할 수 있으므로, 운영체제 간의 호환성 문제를 해결하거나, 다른 운영체제를 시험해보거나, 레거시 애플리케이션을 지원하는 데 유용합니다. 가상 머신은 모놀리식 워크로드를 패키징하는 기존 방식으로, 단일 컨테이너보다 훨씬 더 많은 작업을 실행할 수 있습니다. 하지만, 가상 머신은 운영체제, 애플리케이션, 라이브러리에 의존하므로, 이식성이 떨어지고, 컴퓨팅 자원을 많이 소모합니다. 가상 머신은 다음과 같은 용도에 적합합니다:
> • 기존, 레거시, 모놀리식 워크로드 수용
> • 위험한 개발 사이클 분리
> • 인프라 리소스 (예: 네트워크, 서버, 데이터) 프로비저닝
> • 다른 운영체제에서 또 다른 운영체제 실행 (예: Linux에서 Unix 실행)
> Docker 컨테이너는 애플리케이션 수준의 구성이므로, 커널 하나를 공유하는 여러 가상 환경을 에뮬레이션할 수 있습니다. Docker 컨테이너는 경량화, 빠르고, 효율적으로 리소스를 활용할 수 있습니다. Docker 컨테이너는 표준화, 보안, 통합 등의 장점을 제공하며, 다른 플랫폼과 환경에서도 쉽게 이동할 수 있습니다. Docker 컨테이너는 클라우드 네이티브 애플리케이션을 빌드하고 배포하기에 이상적인 환경입니다. 클라우드 네이티브 애플리케이션은 새로운 애플리케이션의 빌드 방법, 기존 애플리케이션의 최적화 방법, 이 모든 애플리케이션의 연결 방법을 정의하는 방식입니다. Docker 컨테이너는 다음과 같은 용도에 적합합니다:
> • 마이크로서비스 아키텍처 구현
> • 데브옵스 (DevOps) 실천
> • 멀티 클라우드 전략 지원
> • 웹, 모바일, IoT 애플리케이션 개발 및 배포
> Apptainer 컨테이너는 고성능 컴퓨팅 (HPC) 클러스터에서 복잡한 애플리케이션을 간단하고, 이식성 있고, 재현 가능한 방식으로 실행하기 위해 설계된 컨테이너 시스템입니다. Apptainer 컨테이너는 암호화 서명과 암호화를 지원하는 단일 파일 형식이며, 100% OCI 호환되는 Apptainer Engine에서 실행됩니다. Apptainer 컨테이너는 검증 가능한 재현성, 격리보다 통합, 암호화, 컴퓨팅 이동성, 루트 없는 실행 등의 특징을 제공합니다. Apptainer 컨테이너는 산업과 학계에서 다양한 분야의 작업에 널리 사용됩니다. Apptainer 컨테이너는 다음과 같은 용도에 적합합니다:
> • 과학, 공학, 인공지능, 빅데이터, 머신러닝, 딥러닝 등의 HPC 애플리케이션 실행
> • 신뢰성, 보안성, 재현성이 중요한 연구, 실험, 시뮬레이션 수행
> • 다양한 컴퓨팅 환경 (예: 데스크탑, 랩톱, 클라우드, 엣지, 임베디드)에서의 애플리케이션 이동성 확보
> • 루트 권한이 없는 환경에서의 애플리케이션 실행
> 파이썬 가상환경은 파이썬 프로젝트를 작업할 수 있는 격리된 공간입니다. 파이썬 가상환경은 venv 모듈이나 다른 도구들을 사용하여 생성할 수 있습니다. 파이썬 가상환경은 폴더 구조, 격리된 파이썬 설치, pyvenv.cfg 파일로 구성됩니다. 파이썬 가상환경은 시스템 오염을 피하고, 의존성 충돌을 회피하고, 재현성 문제를 최소화하고, 설치 권한 잠금을 피하는 등의 장점을 제공합니다. 파이썬 가상환경은 다음과 같은 용도에 적합합니다:
> • 다양한 파이썬 버전과 라이브러리를 관리하고 사용하기
> • 파이썬 애플리케이션과 라이브러리를 개발, 테스트, 배포하기
> • 파이썬 프로젝트의 의존성과 환경 설정을 공유하고 문서화하기
> • 파이썬 프로젝트의 실행 환경을 재현하기
