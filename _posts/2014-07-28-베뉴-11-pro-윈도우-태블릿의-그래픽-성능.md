델에서 출시한 Venue 11 Pro 윈도우 태블릿을 휴대용 단말로 사용하다가 갑자기 이 태블릿의 그래픽 성능이 어느 정도일까하는 생각이 불현듯 들었다. Venue 11 Pro는 Intel의 베이트레일 아톰 CPU가 탑재된 모델부터 i3, i5 까지 다양한 CPU를 탑재한 모델이 출시되어 판매되고 있다.

윈도우 태블릿은 기존의 아이패드나, 안드로이드 태블릿과는 달리 윈도우 8.1이 설치되어 기존의 데스크탑 PC에서 돌아가는 소프트웨어 들이 바로 실행된다는 점과 안드로이드 태블릿이나 아이패드와 달리 Active X 등 윈도우 전용 프로그램을 문제없이 돌릴 수 있으면서도 휴대가 용이하다는 점에서 나름의 장점이 있어 보인다. 그래서 필자가 윈도우 태블릿이 처음 시장에 나온 2012년 부터 슬래이트 류의 다양한 윈도우 패드 (이때만 해도 태블릿이라고 하기에는 뭐한 패드였다)에 윈도우 8 Preview를 설치해서 테스트를 해보면서 과연 이 물건이 쓸만할까를 고민했던 기억이 난다.

현재 출시된 다양한 윈도우 태블릿 중에서 데스크탑을 치우고 노트북을 데스크탑 대용으로 사용하게 하면서 노트북 대신에 들고 다니고 있는 델 Venue 11 Pro Atom 버전에서 과연 CAD와 같은 작업이 가능할 것인지 또는 외부에서 설계 도면 등을 조회하면서 작업자가 도면 조회 용으로도 사용할 수 있는지를 알아보기 위해서 간단한 3D 그래픽 성능 측정 툴로 그래픽 성능을 측정해 보았다.

## 1. 성능 측정에 사용된 프로그램

일반적으로 그래픽 성능을 측정하는데 가장 많이 사용되는 툴은 SPECviewPerf 인데 현재는 11버전까지 배포되어 있다. 그런데 SPECviewPerf의 모든 성능 측정을 수행할 경우에 많은 시간과 최소한의 시스템 요구사항이 필요하다. 최신 SPECviewPerf 11의 최소 시스템 요구 사항은 다음과 같다. 이와 함께 권고 시스템 사양은 다음과 같다.

#### 1) 최소 시스템 요구 사항

- OpenGL 1.5 plus extensions

- 3GB 시스템 메모리

- 6GB 디스크 용량

- 1920×1080 (SPEC 웹사이트에 제출하고자 할 경우)

#### 2) 권고 사항

- 최소 512MB 이상의 그래픽 메모리

- 32 비트 윈도 시스템의 경우 페이지 파일 사이즈를 “/3GB”로 설정

- 충분한 성능이 되지 않는 시스템에서는 수행이 중단 될 수 있음

이러한 요구 사항만 보더라도 메모리 2GB에 32비트 윈도가 설치된 내장 Intel HD 그래픽의 Venue 11 Pro Atom 버전에서는 SPECviewPerf 가 정상적으로 수행되지 않을 것이라는 예상이 든다. 이러한 이유로 이번 성능 측정은 SPECviewPerf 의 기능 중에서 Pro/ENGINEER Viewset 버전 9를 사용하여 성능을 측정하였다.

SPECviewPerf Pro/E Viewset의 압축파일을 풀어서 실행하면 Pro/ENGINEER로 생성된 3D 이미지에 대해서 다음의 성능을 측정하여 결과를 보여준다.

## 2. 성능 측정 결과

성능 측정은 필자의 노트북(레노버 e440)과 델 Venue 11 Pro Atom 두 시스템에서 수행되었다. 각 시스템의 사양 및 테스트 결과는 다음과 같다.

1) Lenovo E440

- CPU : Intel i3-4000M 2.40GHz

- Memory : 8GB

- OS : Windows 8.1 Enterprise K 64bit

- Graphic : Intel HD Graphics 4600

- 결과 : 9.268 (Weighted Geometric Mean)

![](/gotocloud-co-kr/posts/post-1035/images/i3-300x101.png)

2) Dell Venue 11 Pro Atom

- CPU : Intel Atom Z3770 1.46GHz

- Memory : 2GB

- OS : Windows 8.1 K 32bit

- Graphic : Intel HD Graphics

- 결과 : 2.936 (Weighted Geometric Mean)

![](/gotocloud-co-kr/posts/post-1035/images/venue11-300x100.png)

두 시스템의 결과를 보면 i3 노트북에 내장된 Intel HD 4600에서의 결과 값이 9.268로 Venue 11 Pro Atom의 2.936에 비해 3배 이상의 성능을 보임을 알 수 있다. (참고로 Quadro 4000 그래픽 카드가 장착된 Windows XP 64 bit  워크스테이션에서의 성능 측정값은 73.63 이었다.)

이상으로 간단하게 SPECviewPerf Pro/E Viewset을 이용하여 Venue 11 Pro Atom 윈도 태블릿의 그래픽 성능을 측정한 결과를 살펴보았는데 이 결과를 볼 때 Venue 11 Pro Atom 버전은 그래픽 용도로는 최소한의 도면 조회 정도에 만족하는 것이 타당할 것으로 보이며 3D 용으로나 간단한 CAD 도면 작성을 위해서라면 Atom 버전이 아닌 i3 또는 i5 이상의 윈도 태블릿을 구입하는 것이 좋을 것으로 판단된다. 그러나 작성된 도면에 대해서 작업장이나 외부에서 조회 용도로 사용하는 데에는 휴대성이라는 관점에서 본다면 어느 정도 만족스러운 결과를 얻을 수 있을 것으로 판단된다.

아쉬운 점은 Venue 11 Pro i5 태블릿을 이 테스트를 수행하기 전에 반납하는 바람에 그래픽 성능이 얼마나 되는지를 같이 비교하지 못했다는 점이며 추후 장비가 확보되면 추가로 그 결과도 여기에 업데이트 하고자 한다.
